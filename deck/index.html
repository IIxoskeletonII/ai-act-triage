    Contamination

    The EU AI Act is in the models’ training data. Benchmark contamination (L17), live.

    So retrieval does not improve the label.

    · slide 9 · 2:00 · clock at 11:50 · start of your block · backstops the "why" in Q&A

    • On enter: the keyword baseline scores 9/20 on the dev set. Our agent: 20/20 on dev and 12/12 on the held-out set.
    • Click: switch retrieval off. The same agent with no access to the Act's text also gets 20/20 and 12/12. Identical.
    • Click: the model-size ablation on the 20 dev cases. Sonnet and Haiku, with and without retrieval: tier accuracy is 18/20 in all four.
    • Click: why. The Act is in the models' training data. This is benchmark contamination (L17), live in our own project. So retrieval does not improve the label.
    • If asked "but 16 vs 18?": that is the full pass, tier and citation. The ablation ran before the needs-info tier existed, so E1 and N7 failed in all four configs (that is the 2/20 tier miss). The 16 vs 18 gap is citations: N6 and A1 were citation-rule gaps later fixed; N5 was one Haiku content error.
    • If asked "is the comparison fair?": yes. With and without retrieval were run on the same commit: dev at c12784a, held-out at 7a55f85. The held-out set was run once.
    • If asked "how do you know it's contamination?": no retrieval matches retrieval, and the smaller model matches the larger. Both point to the knowledge already being in the weights. We can't prove which documents were in training. We show it behaviourally.

    Appendix D · the architecture in detail

    One lap of the loop, and the scorer

    The loop

    1 · InputThe description is passed as data; the prompt says instructions inside it are ignored.
    2 · Searchsearch_ai_act(query): hybrid dense + BM25 over 1,246 chunks, each one provision’s own text.
    3 · Readget_provision(id): exact lookup by provision id.
    4 · DecideThe loop ends when the model returns a typed Verdict instead of another tool call.
    5 · CheckCode rejects any cited id, in the verdict or its obligations, that is not a real provision.
    6 · AskIf the tier is needs-info, one clarifying question; the answer is sent back with the description.

    The id-tree citation scorer

    RuleA cited id satisfies the expected id if it is equal or a descendant in the id tree.
    IdsArt N · Art N(p) · Art N(p)(x) · Annex III(4)(a); sub-points (i), (ii) stay inside their point.
    PassExpected Annex III(4), cited Annex III(4)(a) (PG1).
    FailExpected Art 5(1)(h), cited the parent Art 5(1) (A1, early Sonnet RAG run).
    NullNo expected id: passes when it cites nothing unfounded (minimal-risk) or asks a question (needs-info).
